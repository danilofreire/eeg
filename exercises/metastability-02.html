Exercise 7: Hilbert transform of a chirp signal

Create a chirp signal whose frequency sweeps linearly from 5 Hz to 25 Hz over 5 seconds using scipy.signal.chirp. Apply the Hilbert transform. Plot three things on separate subplots:

  1. The chirp signal itself
  2. The instantaneous amplitude (envelope) overlaid on the signal
  3. The instantaneous frequency (computed as the derivative of the unwrapped phase divided by \(2\pi\))

Verify that the instantaneous frequency increases linearly from 5 to 25 Hz.

TipHint

Use scipy.signal.chirp(times, f0=5, t1=5, f1=25) to generate the signal. Apply scipy.signal.hilbert() to get the analytic signal. For instantaneous frequency, first unwrap the phase with np.unwrap(), then take the numerical derivative with np.diff() and divide by (2 * np.pi * dt), where dt = 1 / sfreq. The resulting curve should be a straight line from 5 to 25 Hz (with some noise at the edges from boundary effects).

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import hilbert, chirp

sfreq = 1000
duration = 5.0
times = np.arange(int(sfreq * duration)) / sfreq

# Create a chirp signal: frequency sweeps from 5 Hz to 25 Hz
x = chirp(times, f0=5, t1=duration, f1=25, method="linear")

# Hilbert transform
analytic = hilbert(x)
inst_amplitude = np.abs(analytic)
inst_phase = np.angle(analytic)

# Instantaneous frequency from the unwrapped phase derivative
phase_unwrapped = np.unwrap(inst_phase)
dt = 1.0 / sfreq
inst_freq = np.diff(phase_unwrapped) / (2 * np.pi * dt)
inst_freq_times = times[:-1] + dt / 2  # midpoint times

# Plot
fig, axes = plt.subplots(3, 1, figsize=(10, 9), sharex=True)

# Panel 1: chirp signal
ax = axes[0]
ax.plot(times, x, color="#2c3e50", linewidth=0.5)
ax.set_ylabel("Amplitude")
ax.set_title("Chirp signal (5 to 25 Hz)")

# Panel 2: signal with envelope
ax = axes[1]
ax.plot(times, x, color="#2c3e50", linewidth=0.5, alpha=0.5, label="Signal")
ax.plot(times, inst_amplitude, color="#e74c3c", linewidth=1.5,
        label="Envelope")
ax.plot(times, -inst_amplitude, color="#e74c3c", linewidth=1.5, alpha=0.5)
ax.set_ylabel("Amplitude")
ax.set_title("Signal with instantaneous amplitude envelope")
ax.legend(fontsize=9)

# Panel 3: instantaneous frequency
ax = axes[2]
ax.plot(inst_freq_times, inst_freq, color="#27ae60", linewidth=1)
ax.axhline(5, color="grey", linestyle=":", linewidth=0.5)
ax.axhline(25, color="grey", linestyle=":", linewidth=0.5)
ax.set_ylabel("Frequency (Hz)")
ax.set_xlabel("Time (s)")
ax.set_title("Instantaneous frequency")
ax.set_ylim(0, 35)

plt.tight_layout()
plt.show()

# Verify: check the instantaneous frequency at a few time points
# Trim edges (0.2 s from each end) to avoid boundary effects
trim = int(0.2 * sfreq)
trimmed_times = inst_freq_times[trim:-trim]
trimmed_freq = inst_freq[trim:-trim]

# Expected: linear sweep from 5 to 25 Hz
expected_freq = 5 + (25 - 5) * trimmed_times / duration

print("Instantaneous frequency verification:")
print(f"  At t = 0.5 s: measured = {trimmed_freq[int(0.3 * sfreq)]:.2f} Hz, "
      f"expected = {5 + 20 * 0.5 / duration:.2f} Hz")
print(f"  At t = 2.5 s: measured = {trimmed_freq[int(2.3 * sfreq)]:.2f} Hz, "
      f"expected = {5 + 20 * 2.5 / duration:.2f} Hz")
print(f"  At t = 4.5 s: measured = {trimmed_freq[int(4.3 * sfreq)]:.2f} Hz, "
      f"expected = {5 + 20 * 4.5 / duration:.2f} Hz")
print(f"  Mean absolute error (trimmed): "
      f"{np.mean(np.abs(trimmed_freq - expected_freq)):.4f} Hz")

The envelope should be approximately constant (close to 1.0) across the entire signal, because the chirp has constant amplitude; it only changes frequency. The instantaneous frequency plot should show a clean straight line from 5 Hz at the start to 25 Hz at the end, confirming that the Hilbert transform correctly tracks the changing frequency of the chirp.

This exercise demonstrates that the Hilbert transform works on non-stationary signals whose frequency changes over time. This is important for EEG, where oscillation frequencies drift and are never perfectly constant.

Exercise 8: Narrowband vs broadband phase extraction

Create a signal that is the sum of two oscillations: 10 Hz and 25 Hz, both with amplitude 1. Extract the instantaneous phase using the Hilbert transform in two ways:

  1. Apply the Hilbert transform to the raw broadband signal (no filtering)
  2. Band-pass filter the signal to 8–13 Hz first, then apply the Hilbert transform

Plot both phase time series on separate subplots and compare them. Show that the broadband phase is erratic and meaningless, while the narrowband phase is smooth and tracks the 10 Hz oscillation correctly.

TipHint

Create the signal as np.sin(2 * pi * 10 * t) + np.sin(2 * pi * 25 * t). For the narrowband version, use a 4th-order Butterworth band-pass filter between 8 and 13 Hz with scipy.signal.butter and filtfilt. Apply the Hilbert transform to both versions and extract np.angle(). The broadband phase will jump around because the Hilbert transform cannot assign a single meaningful phase to a signal with two frequency components. The narrowband phase should be a clean sawtooth, just like in Exercise 1.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import hilbert, butter, filtfilt

sfreq = 256
duration = 2.0
times = np.arange(int(sfreq * duration)) / sfreq

# Signal with two frequency components
x = np.sin(2 * np.pi * 10 * times) + np.sin(2 * np.pi * 25 * times)

# --- Broadband: Hilbert on raw signal ---
analytic_broad = hilbert(x)
phase_broad = np.angle(analytic_broad)

# --- Narrowband: filter to 8-13 Hz, then Hilbert ---
b, a = butter(4, [8, 13], btype="band", fs=sfreq)
x_filtered = filtfilt(b, a, x)
analytic_narrow = hilbert(x_filtered)
phase_narrow = np.angle(analytic_narrow)

# Plot
fig, axes = plt.subplots(4, 1, figsize=(10, 10), sharex=True)

# Panel 1: raw signal
ax = axes[0]
ax.plot(times, x, color="#2c3e50", linewidth=0.8)
ax.set_ylabel("Amplitude")
ax.set_title("Raw signal (10 Hz + 25 Hz)")

# Panel 2: filtered signal
ax = axes[1]
ax.plot(times, x_filtered, color="#8e44ad", linewidth=0.8)
ax.set_ylabel("Amplitude")
ax.set_title("Band-pass filtered signal (8-13 Hz)")

# Panel 3: broadband phase
ax = axes[2]
ax.plot(times, phase_broad, color="#e74c3c", linewidth=0.5)
ax.set_ylabel("Phase (rad)")
ax.set_title("Phase from broadband signal (erratic, meaningless)")
ax.set_yticks([-np.pi, 0, np.pi])
ax.set_yticklabels([r"$-\pi$", "0", r"$\pi$"])

# Panel 4: narrowband phase
ax = axes[3]
ax.plot(times, phase_narrow, color="#27ae60", linewidth=0.8)
ax.set_ylabel("Phase (rad)")
ax.set_xlabel("Time (s)")
ax.set_title("Phase from narrowband signal (smooth, meaningful)")
ax.set_yticks([-np.pi, 0, np.pi])
ax.set_yticklabels([r"$-\pi$", "0", r"$\pi$"])

plt.tight_layout()
plt.show()

# Quantify: phase smoothness (mean absolute jump between consecutive samples)
phase_jumps_broad = np.abs(np.diff(phase_broad))
# Wrap jumps to [-pi, pi]
phase_jumps_broad = np.minimum(phase_jumps_broad, 2 * np.pi - phase_jumps_broad)

phase_jumps_narrow = np.abs(np.diff(phase_narrow))
phase_jumps_narrow = np.minimum(phase_jumps_narrow, 2 * np.pi - phase_jumps_narrow)

print("Phase smoothness (mean absolute sample-to-sample jump):")
print(f"  Broadband:  {phase_jumps_broad.mean():.4f} rad/sample")
print(f"  Narrowband: {phase_jumps_narrow.mean():.4f} rad/sample")
print()
print("The narrowband phase jumps should be much smaller and more regular,")
print("corresponding to the steady 10 Hz oscillation advancing by about")
print(f"  2*pi*10/sfreq = {2 * np.pi * 10 / sfreq:.4f} rad/sample.")

The broadband phase looks erratic: it jumps around unpredictably because the Hilbert transform is trying to assign a single phase angle to a signal that contains two distinct frequency components. There is no single meaningful “phase” for such a signal.

The narrowband phase, by contrast, is a clean sawtooth that advances steadily at 10 Hz, because the band-pass filter removed the 25 Hz component and left only the 10 Hz oscillation. This is exactly what the Hilbert transform is designed for: a narrowband analytic signal with a single dominant oscillation.

The lesson is simple but important: always filter to a narrow frequency band before applying the Hilbert transform. This is a non-negotiable step in the metastability pipeline.

Exercise 9: Compute PLV between two channels

Create two channels, both oscillating at 10 Hz, with time-varying coupling: they are synchronised for the first half of the recording and desynchronised for the second half. Compute the phase-locking value (PLV) in sliding windows (1-second windows, stepping by 0.5 seconds). Plot PLV over time and verify that it is high in the first half and low in the second.

TipHint

Generate the first channel as a 10 Hz sine wave. For the second channel, use the same sine for the first half but add a random phase jitter in the second half: ch2_second_half = np.sin(2*pi*10*t + random_walk), where the random walk accumulates noise over time, destroying the phase relationship.

PLV in a window is computed as: PLV = |mean(exp(i * (phase1 - phase2)))| over all samples in the window. A PLV near 1 means the phase difference is constant (synchronised); a PLV near 0 means the phase difference is uniformly distributed (desynchronised).

Band-pass filter both channels to 8–13 Hz before extracting the phase.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import hilbert, butter, filtfilt

rng = np.random.default_rng(42)

sfreq = 256
duration = 10.0  # seconds
n_samples = int(sfreq * duration)
times = np.arange(n_samples) / sfreq
half = n_samples // 2

# Channel 1: clean 10 Hz sine wave throughout
ch1 = np.sin(2 * np.pi * 10 * times) + 0.2 * rng.standard_normal(n_samples)

# Channel 2: synchronised in first half, desynchronised in second half
ch2 = np.zeros(n_samples)
# First half: same 10 Hz sine (with small noise)
ch2[:half] = (np.sin(2 * np.pi * 10 * times[:half])
              + 0.2 * rng.standard_normal(half))
# Second half: 10 Hz sine with a random phase walk
random_phase = np.cumsum(rng.standard_normal(n_samples - half) * 0.3)
ch2[half:] = (np.sin(2 * np.pi * 10 * times[half:] + random_phase)
              + 0.2 * rng.standard_normal(n_samples - half))

# Band-pass filter 8-13 Hz
b, a = butter(4, [8, 13], btype="band", fs=sfreq)
ch1_filt = filtfilt(b, a, ch1)
ch2_filt = filtfilt(b, a, ch2)

# Extract instantaneous phase
phase1 = np.angle(hilbert(ch1_filt))
phase2 = np.angle(hilbert(ch2_filt))

# Compute PLV in sliding windows
win_sec = 1.0
step_sec = 0.5
win_samples = int(win_sec * sfreq)
step_samples = int(step_sec * sfreq)

plv_values = []
plv_times = []

start = 0
while start + win_samples <= n_samples:
    end = start + win_samples
    phase_diff = phase1[start:end] - phase2[start:end]
    plv = np.abs(np.mean(np.exp(1j * phase_diff)))
    plv_values.append(plv)
    plv_times.append((start + win_samples / 2) / sfreq)  # window centre
    start += step_samples

plv_values = np.array(plv_values)
plv_times = np.array(plv_times)

# Plot
fig, axes = plt.subplots(3, 1, figsize=(10, 8), sharex=True)

# Panel 1: channel 1
ax = axes[0]
ax.plot(times, ch1_filt, color="#2c3e50", linewidth=0.5)
ax.set_ylabel("Amplitude")
ax.set_title("Channel 1 (filtered 8-13 Hz)")

# Panel 2: channel 2
ax = axes[1]
ax.plot(times, ch2_filt, color="#8e44ad", linewidth=0.5)
ax.axvline(duration / 2, color="#e74c3c", linestyle="--", linewidth=1,
           label="Coupling change")
ax.set_ylabel("Amplitude")
ax.set_title("Channel 2 (filtered 8-13 Hz)")
ax.legend(fontsize=9)

# Panel 3: PLV over time
ax = axes[2]
ax.plot(plv_times, plv_values, color="#27ae60", linewidth=2, marker="o",
        markersize=4)
ax.axvline(duration / 2, color="#e74c3c", linestyle="--", linewidth=1,
           label="Coupling change")
ax.axhline(0.5, color="grey", linestyle=":", linewidth=0.5)
ax.set_ylabel("PLV")
ax.set_xlabel("Time (s)")
ax.set_title("Phase-locking value (1-second sliding windows)")
ax.set_ylim(0, 1.05)
ax.legend(fontsize=9)

plt.tight_layout()
plt.show()

# Summary statistics
first_half_plv = plv_values[plv_times < duration / 2]
second_half_plv = plv_values[plv_times >= duration / 2]

print("PLV summary:")
print(f"  First half (synchronised):    mean PLV = {first_half_plv.mean():.3f}")
print(f"  Second half (desynchronised): mean PLV = {second_half_plv.mean():.3f}")
print(f"  Difference: {first_half_plv.mean() - second_half_plv.mean():.3f}")

The PLV should be high (close to 1.0) during the first half, when the two channels share the same 10 Hz oscillation with only small noise perturbations. In the second half, the random phase walk destroys the phase relationship, so the PLV drops toward lower values.

PLV is one of the most widely used measures of functional connectivity in EEG research. It quantifies how consistent the phase relationship between two signals is over a given time window. A high PLV does not mean the channels have the same phase; it means their phase difference is stable (it could be zero, or \(\pi/3\), or any fixed offset). A low PLV means the phase difference wanders around, indicating no stable coupling.

Exercise 10: Build a full PLV connectivity matrix

Simulate 8 channels in two groups:

  • Channels 0–3 are synchronised with each other (they share a common 10 Hz oscillation)
  • Channels 4–7 are synchronised with each other (they share a different common 10 Hz oscillation)
  • The two groups are independent of each other

Compute the pairwise PLV matrix (8 x 8) using the full recording. Display it as a heatmap. Verify the block-diagonal structure: high PLV within each group, low PLV between the two groups.

TipHint

Create two independent reference oscillations (both at 10 Hz but with unrelated phase). For channels 0–3, mix each channel as 0.9 * ref_1 + 0.1 * independent_noise. For channels 4–7, do the same with ref_2. This ensures that channels within a group are strongly coupled to each other (through the shared reference) but channels in different groups are not.

After band-pass filtering and extracting phases, compute PLV for every pair (i, j) using the full recording: PLV_ij = |mean(exp(i * (phase_i - phase_j)))|. Store the results in an 8 x 8 matrix and use plt.imshow() with plt.colorbar() to display the heatmap.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import hilbert, butter, filtfilt

rng = np.random.default_rng(42)

sfreq = 256
duration = 30.0
n_samples = int(sfreq * duration)
times = np.arange(n_samples) / sfreq
n_channels = 8

# Two independent reference oscillations at 10 Hz
ref1_phase = (2 * np.pi * 10 * times
              + 0.2 * np.cumsum(rng.standard_normal(n_samples) / sfreq))
ref1 = np.sin(ref1_phase)

ref2_phase = (2 * np.pi * 10 * times
              + 0.2 * np.cumsum(rng.standard_normal(n_samples) / sfreq))
ref2 = np.sin(ref2_phase)

# Generate 8 channels
data = np.zeros((n_channels, n_samples))
coupling = 0.9

for ch in range(4):
    noise = rng.standard_normal(n_samples)
    ind_phase = (2 * np.pi * 10 * times
                 + 2.0 * np.cumsum(rng.standard_normal(n_samples) / sfreq))
    ind_signal = np.sin(ind_phase)
    data[ch] = coupling * ref1 + (1 - coupling) * ind_signal + 0.2 * noise

for ch in range(4, 8):
    noise = rng.standard_normal(n_samples)
    ind_phase = (2 * np.pi * 10 * times
                 + 2.0 * np.cumsum(rng.standard_normal(n_samples) / sfreq))
    ind_signal = np.sin(ind_phase)
    data[ch] = coupling * ref2 + (1 - coupling) * ind_signal + 0.2 * noise

# Band-pass filter and extract phase
b, a = butter(4, [8, 13], btype="band", fs=sfreq)
phases = np.zeros_like(data)
for ch in range(n_channels):
    filtered = filtfilt(b, a, data[ch])
    phases[ch] = np.angle(hilbert(filtered))

# Compute pairwise PLV matrix
plv_matrix = np.zeros((n_channels, n_channels))
for i in range(n_channels):
    for j in range(n_channels):
        phase_diff = phases[i] - phases[j]
        plv_matrix[i, j] = np.abs(np.mean(np.exp(1j * phase_diff)))

# Plot heatmap
channel_labels = [f"Ch{i}" for i in range(n_channels)]

fig, ax = plt.subplots(figsize=(7, 6))
im = ax.imshow(plv_matrix, cmap="RdYlBu_r", vmin=0, vmax=1, aspect="equal")
ax.set_xticks(range(n_channels))
ax.set_xticklabels(channel_labels, fontsize=9)
ax.set_yticks(range(n_channels))
ax.set_yticklabels(channel_labels, fontsize=9)
ax.set_title("PLV connectivity matrix")
plt.colorbar(im, ax=ax, label="PLV", shrink=0.8)

# Add value annotations
for i in range(n_channels):
    for j in range(n_channels):
        colour = "white" if plv_matrix[i, j] > 0.7 else "black"
        ax.text(j, i, f"{plv_matrix[i, j]:.2f}",
                ha="center", va="center", fontsize=8, color=colour)

plt.tight_layout()
plt.show()

# Print block structure
print("PLV matrix summary:")
within_group1 = plv_matrix[:4, :4][np.triu_indices(4, k=1)]
within_group2 = plv_matrix[4:, 4:][np.triu_indices(4, k=1)]
between_groups = plv_matrix[:4, 4:].ravel()

print(f"  Within group 1 (Ch0-3): mean PLV = {within_group1.mean():.3f}")
print(f"  Within group 2 (Ch4-7): mean PLV = {within_group2.mean():.3f}")
print(f"  Between groups:         mean PLV = {between_groups.mean():.3f}")

The heatmap should show a clear block-diagonal structure: two bright squares along the diagonal (channels 0–3 coupled with each other, channels 4–7 coupled with each other) and dim off-diagonal blocks (low PLV between the two groups). This is exactly what you would expect from the simulation: each group shares a common reference oscillation, so channels within a group are phase-locked, but the two references are independent, so channels in different groups are not.

In real EEG data, the connectivity matrix is rarely this clean. The block structure will be noisier, and the groupings will depend on the frequency band, the task, and the individual. But the principle is the same: the PLV matrix reveals which channels are functionally coupled and which are not.

Exercise 11: Visualise PLV as a network graph

Using the PLV matrix from Exercise 10, threshold it (keep only connections with PLV > 0.5) and visualise the result as a network graph. Place the 8 channel nodes in a circle and draw edges between nodes whose PLV exceeds the threshold. Use edge thickness proportional to PLV strength. This gives a quick visual summary of the functional connectivity pattern.

TipHint

Arrange the 8 nodes evenly around a circle using polar coordinates: x = cos(2*pi*k/8), y = sin(2*pi*k/8) for channel k. Loop over all unique pairs (i, j) with i < j. If PLV[i, j] > threshold, draw a line between node i and node j using plt.plot(). Set the line width proportional to PLV, e.g., linewidth = 3 * PLV[i, j]. Draw the nodes as scatter points on top.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import hilbert, butter, filtfilt

rng = np.random.default_rng(42)

# ── Reproduce the PLV matrix from Exercise 10 ───────────────
sfreq = 256
duration = 30.0
n_samples = int(sfreq * duration)
times = np.arange(n_samples) / sfreq
n_channels = 8
coupling = 0.9

ref1_phase = (2 * np.pi * 10 * times
              + 0.2 * np.cumsum(rng.standard_normal(n_samples) / sfreq))
ref1 = np.sin(ref1_phase)
ref2_phase = (2 * np.pi * 10 * times
              + 0.2 * np.cumsum(rng.standard_normal(n_samples) / sfreq))
ref2 = np.sin(ref2_phase)

data = np.zeros((n_channels, n_samples))
for ch in range(4):
    ind_phase = (2 * np.pi * 10 * times
                 + 2.0 * np.cumsum(rng.standard_normal(n_samples) / sfreq))
    data[ch] = (coupling * ref1 + (1 - coupling) * np.sin(ind_phase)
                + 0.2 * rng.standard_normal(n_samples))
for ch in range(4, 8):
    ind_phase = (2 * np.pi * 10 * times
                 + 2.0 * np.cumsum(rng.standard_normal(n_samples) / sfreq))
    data[ch] = (coupling * ref2 + (1 - coupling) * np.sin(ind_phase)
                + 0.2 * rng.standard_normal(n_samples))

b, a = butter(4, [8, 13], btype="band", fs=sfreq)
phases = np.zeros_like(data)
for ch in range(n_channels):
    phases[ch] = np.angle(hilbert(filtfilt(b, a, data[ch])))

plv_matrix = np.zeros((n_channels, n_channels))
for i in range(n_channels):
    for j in range(n_channels):
        plv_matrix[i, j] = np.abs(np.mean(np.exp(1j * (phases[i] - phases[j]))))

# ── Network graph ────────────────────────────────────────────
threshold = 0.5
channel_labels = [f"Ch{i}" for i in range(n_channels)]

# Place nodes in a circle
angles = np.linspace(0, 2 * np.pi, n_channels, endpoint=False)
# Start from the top (pi/2) and go clockwise
angles = np.pi / 2 - angles
node_x = np.cos(angles)
node_y = np.sin(angles)

fig, ax = plt.subplots(figsize=(7, 7))

# Draw edges for suprathreshold PLV
n_edges = 0
for i in range(n_channels):
    for j in range(i + 1, n_channels):
        if plv_matrix[i, j] > threshold:
            # Colour by group membership
            if i < 4 and j < 4:
                colour = "#3498db"  # within group 1
            elif i >= 4 and j >= 4:
                colour = "#e74c3c"  # within group 2
            else:
                colour = "#95a5a6"  # between groups
            lw = 4 * plv_matrix[i, j]
            ax.plot([node_x[i], node_x[j]], [node_y[i], node_y[j]],
                    color=colour, linewidth=lw, alpha=0.6, zorder=1)
            n_edges += 1

# Draw nodes
colours = ["#3498db"] * 4 + ["#e74c3c"] * 4
ax.scatter(node_x, node_y, s=500, c=colours, edgecolors="#2c3e50",
           linewidths=2, zorder=3)

# Label nodes
for i in range(n_channels):
    ax.text(node_x[i], node_y[i], channel_labels[i],
            ha="center", va="center", fontsize=10, fontweight="bold",
            color="white", zorder=4)

ax.set_xlim(-1.5, 1.5)
ax.set_ylim(-1.5, 1.5)
ax.set_aspect("equal")
ax.set_title(f"PLV network (threshold = {threshold}, {n_edges} edges)")
ax.axis("off")

plt.tight_layout()
plt.show()

TipHint

\(R(t)\) measures the degree of phase coherence across all channels at time \(t\). It ranges from 0 (completely desynchronised, phases uniformly spread around the circle) to 1 (all phases identical, perfect synchronisation). At each time point, take the vector of phases \(\phi_1(t), \ldots, \phi_N(t)\), compute the complex mean \(\frac{1}{N}\sum e^{i\phi_k}\), and take its absolute value. import numpy as np
from scipy.signal import hilbert, butter, filtfilt


def metastability_report(data, sfreq, bands, channel_names):
    """Run a complete metastability analysis and print a summary.

    Parameters
    ----------
    data : ndarray, shape (n_channels, n_samples)
        Multi-channel EEG data.
    sfreq : float
        Sampling frequency in Hz.
    bands : dict
        Frequency bands. Keys are band names (str), values are dicts
        with 'lo' and 'hi' keys (filter edges in Hz).
        Example: {"Alpha": {"lo": 8, "hi": 13}}
    channel_names : list of str
        Names for each channel.

    Returns
    -------
    results : dict
        Nested dictionary with results for each band:
        - 'regional_ms': array of regional metastability per channel
        - 'eigvec_series': dominant eigenvector time series
        - 'r_t': Kuramoto R(t)
        - 'global_ms': Var(R)
        - 'mean_regional_ms': mean across channels
    """
    n_ch, n_samp = data.shape
    results = {}

    for band_name, band_params in bands.items():
        lo = band_params["lo"]
        hi = band_params["hi"]

        # Band-pass filter and extract phases
        b, a = butter(4, [lo, hi], btype="band", fs=sfreq)
        phases = np.zeros_like(data)
        for ch in range(n_ch):
            phases[ch] = np.angle(hilbert(filtfilt(b, a, data[ch])))

        # Kuramoto order parameter R(t)
        complex_order = np.mean(np.exp(1j * phases), axis=0)
        r_t = np.abs(complex_order)
        global_ms = np.var(r_t)

        # Eigenvector decomposition for regional metastability
        step = max(1, sfreq // 100)
        time_indices = np.arange(0, n_samp, step)
        n_tp = len(time_indices)
        eigvec_series = np.zeros((n_ch, n_tp))

        for ti, t in enumerate(time_indices):
            phi = phases[:, t]
            phase_diff = phi[:, None] - phi[None, :]
            A = np.cos(phase_diff)
            eigenvalues, eigenvectors = np.linalg.eigh(A)
            dominant = eigenvectors[:, -1]
            if ti > 0 and np.dot(dominant, eigvec_series[:, ti - 1]) < 0:
                dominant = -dominant
            eigvec_series[:, ti] = dominant

        regional_ms = np.var(eigvec_series, axis=1)

        results[band_name] = {
            "regional_ms": regional_ms,
            "eigvec_series": eigvec_series,
            "r_t": r_t,
            "global_ms": global_ms,
            "mean_regional_ms": regional_ms.mean(),
        }

    # ── Print formatted summary ─────────────────────────────
    print("=" * 70)
    print("METASTABILITY ANALYSIS REPORT")
    print("=" * 70)
    print(f"  Channels:        {n_ch}")
    print(f"  Sampling rate:   {sfreq} Hz")
    print(f"  Duration:        {n_samp / sfreq:.1f} s")
    print(f"  Frequency bands: {len(bands)}")
    print()

    # Band summary table
    header = f"{'Band':<20} {'Global MS':>12} {'Mean Reg MS':>14} {'Max Ch':>12} {'Min Ch':>12}"
    print(header)
    print("-" * len(header))

    for band_name, res in results.items():
        ms = res["regional_ms"]
        max_ch = channel_names[np.argmax(ms)]
        min_ch = channel_names[np.argmin(ms)]
        print(f"{band_name:<20} {res['global_ms']:>12.6f} "
              f"{res['mean_regional_ms']:>14.6f} "
              f"{max_ch:>12} {min_ch:>12}")

    print()

    # Per-channel breakdown
    print("Per-channel regional metastability:")
    header2 = f"{'Channel':<10}"
    for band_name in bands:
        header2 += f" {band_name:>14}"
    print(header2)
    print("-" * len(header2))

    for ch in range(n_ch):
        row = f"{channel_names[ch]:<10}"
        for band_name in bands:
            row += f" {results[band_name]['regional_ms'][ch]:>14.6f}"
        print(row)

    print()
    print("=" * 70)

    return results
