Exercise 1: Reject epochs by peak-to-peak amplitude

Create epoched data where some epochs contain large-amplitude bursts (simulating muscle artifacts). Reject any epoch where the peak-to-peak amplitude exceeds 100 µV. Report how many epochs were rejected and how many survived.

TipHint

Create a Raw object, add events with mne.make_fixed_length_events(), and build Epochs from them. To inject artifacts into some epochs, pick a few event times and add a large spike to the data at those times before epoching. Use the reject parameter in mne.Epochs(): pass reject=dict(eeg=100e-6) to reject epochs where any EEG channel exceeds 100 µV peak-to-peak. After creating the Epochs object, call epochs.drop_log to see which epochs were dropped.

NoteSolution 
import numpy as np
import mne

sfreq = 500
duration = 60
times = np.arange(0, duration, 1 / sfreq)
n_samples = len(times)

ch_names = ["Fp1", "Fp2", "C3", "C4", "P3", "P4", "O1", "O2"]
n_channels = len(ch_names)
info = mne.create_info(ch_names=ch_names, sfreq=sfreq, ch_types="eeg")

# Create clean EEG-like data
data = np.random.randn(n_channels, n_samples) * 10e-6

# Inject large artifacts at known times (simulating muscle bursts)
# Add a 200 µV spike lasting 100 ms at these times:
artifact_times = [5.0, 12.3, 25.7, 33.1, 41.5, 52.8]
for t_art in artifact_times:
    start = int(t_art * sfreq)
    end = start + int(0.1 * sfreq)  # 100 ms burst
    if end < n_samples:
        data[:, start:end] += 200e-6 * np.random.randn(n_channels, end - start)

raw = mne.io.RawArray(data, info)

# Create 2-second epochs
events = mne.make_fixed_length_events(raw, duration=2.0)

# Build epochs with peak-to-peak rejection at 100 µV
epochs = mne.Epochs(
    raw, events,
    tmin=0, tmax=2.0,
    baseline=None,
    reject=dict(eeg=100e-6),
    preload=True
)

# Report the results
n_total = len(events)
n_kept = len(epochs)
n_rejected = n_total - n_kept

print(f"Total epochs: {n_total}")
print(f"Kept: {n_kept}")
print(f"Rejected: {n_rejected}")

# Show the drop log (which epochs were dropped and why)
epochs.plot_drop_log()

The exact number of rejected epochs depends on where the artifacts fall relative to the epoch boundaries, but you should see roughly 6 epochs rejected (one per artifact burst). Epochs that did not overlap with any artifact time should survive.

Exercise 2: Run ICA and plot component topographies

Run ICA with 15 components on simulated multi-channel data. Plot the component topographies to see how ICA decomposes the data.

TipHint

Create a Raw object with at least 20 channels and set a standard montage (ICA topography plots need channel positions). Use mne.preprocessing.ICA(n_components=15, random_state=42) and call ica.fit(raw). Then ica.plot_components() shows the scalp maps.

NoteSolution 
import numpy as np
import mne
from mne.preprocessing import ICA

sfreq = 500
duration = 120  # ICA works better with more data
times = np.arange(0, duration, 1 / sfreq)
n_samples = len(times)

# Use 20 channels so we have enough for 15 ICA components
ch_names = [
    "Fp1", "Fp2", "F3", "F4", "F7", "F8", "Fz",
    "C3", "C4", "Cz",
    "T7", "T8",
    "P3", "P4", "P7", "P8", "Pz",
    "O1", "O2", "Oz"
]
n_channels = len(ch_names)
info = mne.create_info(ch_names=ch_names, sfreq=sfreq, ch_types="eeg")

# Simulate data: mix of oscillations at different frequencies per region
data = np.random.randn(n_channels, n_samples) * 5e-6

# Add alpha to occipital channels
alpha = 10e-6 * np.sin(2 * np.pi * 10 * times)
for name in ["O1", "O2", "Oz"]:
    data[ch_names.index(name)] += alpha

# Add beta to central channels
beta = 6e-6 * np.sin(2 * np.pi * 20 * times)
for name in ["C3", "C4", "Cz"]:
    data[ch_names.index(name)] += beta

raw = mne.io.RawArray(data, info)

# Set montage (required for topography plots)
montage = mne.channels.make_standard_montage("standard_1020")
raw.set_montage(montage)

# Band-pass filter before ICA (1 Hz high-pass helps ICA converge)
raw.filter(l_freq=1, h_freq=40)

# Fit ICA
ica = ICA(n_components=15, random_state=42)
ica.fit(raw)

print(ica)

# Plot component topographies
ica.plot_components(title="ICA components")

Each component map shows a spatial pattern. With simulated data like this, you may see components that capture the occipital alpha pattern, the central beta pattern, and several noise components. With real data, you would look for components that match the spatial signature of known artifacts (blinks in frontal channels, lateral eye movements, etc.).

Exercise 3: Simulate and remove a blink artifact with ICA

Create data with a simulated blink artifact: a large, brief deflection on frontal channels ("Fp1", "Fp2") that repeats every 3 seconds. Run ICA, identify the blink component, exclude it, and apply the cleaning. Compare the frontal signal before and after.

TipHint

Create the blink as a Gaussian pulse (use scipy.signal.windows.gaussian() or just np.exp(-0.5 * ((t - t_blink) / width)**2)) with a large amplitude (say 80 µV) added mainly to Fp1 and Fp2 and with smaller contributions to nearby channels. After fitting ICA, use ica.find_blinks() or inspect the components manually with ica.plot_sources(raw). Exclude the blink component with ica.exclude = [component_index] and then ica.apply(raw).

NoteSolution 
import numpy as np
import mne
from mne.preprocessing import ICA
import matplotlib.pyplot as plt

sfreq = 500
duration = 120
times = np.arange(0, duration, 1 / sfreq)
n_samples = len(times)

ch_names = [
    "Fp1", "Fp2", "F3", "F4", "F7", "F8", "Fz",
    "C3", "C4", "Cz",
    "T7", "T8",
    "P3", "P4", "P7", "P8", "Pz",
    "O1", "O2", "Oz"
]
n_channels = len(ch_names)
info = mne.create_info(ch_names=ch_names, sfreq=sfreq, ch_types="eeg")

# Clean EEG: alpha oscillation plus noise
data = np.random.randn(n_channels, n_samples) * 5e-6
alpha = 10e-6 * np.sin(2 * np.pi * 10 * times)
for name in ["O1", "O2", "Oz", "P3", "P4", "Pz"]:
    data[ch_names.index(name)] += alpha

# Store a copy of clean data for comparison
data_clean = data.copy()

# Add blink artifacts every 3 seconds on frontal channels
blink_width = 0.15  # seconds (width of the Gaussian pulse)
blink_times = np.arange(1.5, duration - 1, 3.0)  # every 3 seconds

for t_blink in blink_times:
    # Gaussian pulse centred at t_blink
    pulse = np.exp(-0.5 * ((times - t_blink) / blink_width) ** 2)

    # Blink is strongest at Fp1/Fp2, weaker at F3/F4/Fz/F7/F8
    data[ch_names.index("Fp1")] += 80e-6 * pulse
    data[ch_names.index("Fp2")] += 80e-6 * pulse
    for name in ["F3", "F4", "Fz"]:
        data[ch_names.index(name)] += 30e-6 * pulse
    for name in ["F7", "F8"]:
        data[ch_names.index(name)] += 15e-6 * pulse

raw = mne.io.RawArray(data, info)
montage = mne.channels.make_standard_montage("standard_1020")
raw.set_montage(montage)

# Filter before ICA
raw.filter(l_freq=1, h_freq=40)

# Store Fp1 before ICA cleaning
fp1_before = raw.get_data(picks="Fp1")[0].copy()

# Fit ICA
ica = ICA(n_components=15, random_state=42)
ica.fit(raw)

# Find the blink component automatically using EOG-like detection on Fp1
# (Fp1 acts as a proxy for an EOG channel here)
blink_indices, blink_scores = ica.find_bads_eog(
    raw, ch_name="Fp1", threshold=2.0
)
print(f"Blink component(s) found: {blink_indices}")

# Exclude the blink component(s) and apply
ica.exclude = blink_indices
ica.apply(raw)

fp1_after = raw.get_data(picks="Fp1")[0]

# Compare before and after
fig, axes = plt.subplots(2, 1, figsize=(14, 6), sharex=True)
t_plot = slice(0, int(10 * sfreq))  # first 10 seconds
t_sec = times[:int(10 * sfreq)]

axes[0].plot(t_sec, fp1_before[t_plot] * 1e6)
axes[0].set_title("Fp1 before ICA blink removal")
axes[0].set_ylabel("Amplitude (µV)")

axes[1].plot(t_sec, fp1_after[t_plot] * 1e6)
axes[1].set_title("Fp1 after ICA blink removal")
axes[1].set_ylabel("Amplitude (µV)")
axes[1].set_xlabel("Time (s)")

plt.tight_layout()
plt.show()

The “before” plot should show clear blink-shaped bumps every 3 seconds on the Fp1 channel. After ICA cleaning, those bumps should be gone (or greatly reduced) while the background EEG signal is preserved.

Exercise 4: Compare PSD before and after ICA cleaning

Using the blink-removal pipeline from Exercise 3, plot the PSD of the data before and after ICA cleaning. Pay attention to the low-frequency range (below 5 Hz), where blink artifacts contribute most of their power.

TipHint

Make a copy of the Raw object before applying ica.apply(). Then compute and plot the PSD for both copies using raw.compute_psd().plot(). Focus on the 0–40 Hz range. Blink artifacts are mostly low-frequency (below 3–4 Hz), so you should see a reduction in power in that range after cleaning.

Exercise 5: Threshold-based artifact detector

Write a function that scans a Raw object in fixed-length windows and flags any window where any channel exceeds a threshold of plus or minus 75 µV. Return a list of (start_time, end_time) tuples for the bad segments. Test it on simulated data with known artifacts.

TipHint

Use raw.get_data() to get the data matrix and work in NumPy. Divide the data into windows of, say, 1 second (i.e., sfreq samples). For each window, check whether np.max(np.abs(window)) exceeds 75e-6. If it does, record the start and end times. You can convert sample indices to times by dividing by sfreq.

NoteSolution 
import numpy as np
import mne


def detect_artifacts(raw, threshold_uv=75, window_sec=1.0):
    """Find segments where any channel exceeds the amplitude threshold.

    Parameters
    ----------
    raw : mne.io.Raw
        The raw data to scan.
    threshold_uv : float
        Threshold in microvolts. Any window where a channel exceeds
        this value (positive or negative) is flagged.
    window_sec : float
        Length of each scanning window in seconds.

    Returns
    -------
    bad_segments : list of tuple
        Each tuple is (start_time, end_time) in seconds.
    """
    sfreq = raw.info["sfreq"]
    data = raw.get_data()  # shape: (n_channels, n_samples)
    threshold_v = threshold_uv * 1e-6  # convert µV to V

    window_samples = int(window_sec * sfreq)
    n_samples = data.shape[1]
    bad_segments = []

    for start in range(0, n_samples, window_samples):
        end = min(start + window_samples, n_samples)
        window = data[:, start:end]

        if np.max(np.abs(window)) > threshold_v:
            t_start = start / sfreq
            t_end = end / sfreq
            bad_segments.append((t_start, t_end))

    return bad_segments


# Test on simulated data
sfreq = 500
duration = 30
times = np.arange(0, duration, 1 / sfreq)
n_samples = len(times)

ch_names = ["Fp1", "Fp2", "C3", "C4", "O1", "O2"]
info = mne.create_info(ch_names=ch_names, sfreq=sfreq, ch_types="eeg")
data = np.random.randn(len(ch_names), n_samples) * 10e-6  # ~10 µV noise

# Inject artifacts at known times
artifact_info = [
    (3.2, "Fp1"),   # blink at 3.2 s
    (10.5, "C3"),   # muscle artifact at 10.5 s
    (22.0, "O1"),   # movement at 22 s
]

for t_art, ch in artifact_info:
    ch_idx = ch_names.index(ch)
    sample = int(t_art * sfreq)
    # Add a 150 µV spike lasting 50 ms
    spike_len = int(0.05 * sfreq)
    data[ch_idx, sample:sample + spike_len] += 150e-6

raw = mne.io.RawArray(data, info)

# Run the detector
bad_segs = detect_artifacts(raw, threshold_uv=75, window_sec=1.0)

print(f"Found {len(bad_segs)} bad segments:")
for start, end in bad_segs:
    print(f"  {start:.1f} - {end:.1f} s")

# Verify: we expect 3 bad segments (one per injected artifact)
# The exact window boundaries depend on where the artifact falls,
# but each artifact should flag exactly one 1-second window.

You should see three bad segments, one for each injected artifact. The start and end times will be rounded to 1-second window boundaries (e.g., the artifact at 3.2 seconds falls in the 3.0–4.0 second window). If you want finer resolution, reduce window_sec to 0.5 or 0.25 seconds.

Exercise 6: Simulate four artifact types and identify them

Create a 20-channel recording with four types of injected artifacts: blinks on Fp1/Fp2 (slow, large Gaussian pulses), saccades on F7/F8 (step functions), EMG on T7/T8 (high-frequency bursts), and ECG on all channels (sharp periodic peaks at roughly 1 Hz). Plot each artifact type on its characteristic channel.

TipHint

Start with a 20-channel Raw object filled with low-amplitude noise. Add each artifact type separately: use np.exp(...) for Gaussian blink pulses, np.heaviside() for saccade steps, np.random.randn() band-passed or multiplied by a high-frequency sine for EMG bursts, and a sharp Gaussian pulse repeated at 1 Hz for the ECG. Plot a 10-second window on one representative channel per artifact type using matplotlib.

NoteSolution 
import numpy as np
import mne
import matplotlib.pyplot as plt

sfreq = 500
duration = 60
times = np.arange(0, duration, 1 / sfreq)
n_samples = len(times)

ch_names = [
    "Fp1", "Fp2", "F3", "F4", "F7", "F8", "Fz",
    "C3", "C4", "Cz",
    "T7", "T8",
    "P3", "P4", "P7", "P8", "Pz",
    "O1", "O2", "Oz"
]
n_channels = len(ch_names)
info = mne.create_info(ch_names=ch_names, sfreq=sfreq, ch_types="eeg")

# Baseline noise
data = np.random.randn(n_channels, n_samples) * 5e-6

# --- 1. Blink artifacts on Fp1/Fp2 (Gaussian pulses every ~3 s) ---
blink_times = np.arange(1.5, duration - 1, 3.0)
for t_blink in blink_times:
    pulse = np.exp(-0.5 * ((times - t_blink) / 0.15) ** 2)
    data[ch_names.index("Fp1")] += 80e-6 * pulse
    data[ch_names.index("Fp2")] += 75e-6 * pulse

# --- 2. Saccade artifacts on F7/F8 (step functions, opposite polarity) ---
saccade_times = [8.0, 20.0, 35.0, 50.0]
for t_sac in saccade_times:
    # Step lasts 0.5 s then returns to baseline
    start_samp = int(t_sac * sfreq)
    end_samp = start_samp + int(0.5 * sfreq)
    if end_samp < n_samples:
        data[ch_names.index("F7"), start_samp:end_samp] += 40e-6
        data[ch_names.index("F8"), start_samp:end_samp] -= 40e-6

# --- 3. EMG bursts on T7/T8 (high-frequency noise) ---
emg_times = [5.0, 15.0, 28.0, 42.0]
for t_emg in emg_times:
    start_samp = int(t_emg * sfreq)
    burst_len = int(0.3 * sfreq)  # 300 ms burst
    end_samp = start_samp + burst_len
    if end_samp < n_samples:
        emg_burst = np.random.randn(burst_len) * 30e-6
        # Give it a high-frequency character by modulating with a fast sine
        hf_carrier = np.sin(2 * np.pi * 80 * np.arange(burst_len) / sfreq)
        emg_burst *= np.abs(hf_carrier) + 0.5
        data[ch_names.index("T7"), start_samp:end_samp] += emg_burst
        data[ch_names.index("T8"), start_samp:end_samp] += emg_burst * 0.8

# --- 4. ECG artifact on all channels (sharp periodic peaks at ~1 Hz) ---
ecg_times = np.arange(0.5, duration, 1.0)  # ~1 Hz heartbeat
for t_ecg in ecg_times:
    # QRS-like sharp pulse (narrow Gaussian, width ~20 ms)
    qrs_pulse = np.exp(-0.5 * ((times - t_ecg) / 0.02) ** 2)
    # ECG appears weakly on all channels
    for ch_idx in range(n_channels):
        data[ch_idx] += 8e-6 * qrs_pulse

raw = mne.io.RawArray(data, info)

# Plot one representative channel per artifact type (first 10 seconds)
fig, axes = plt.subplots(4, 1, figsize=(14, 10), sharex=True)
t_plot = slice(0, int(10 * sfreq))
t_sec = times[:int(10 * sfreq)]

axes[0].plot(t_sec, raw.get_data(picks="Fp1")[0, t_plot] * 1e6)
axes[0].set_title("Fp1 -- blink artifacts (Gaussian pulses)")
axes[0].set_ylabel("uV")

axes[1].plot(t_sec, raw.get_data(picks="F7")[0, t_plot] * 1e6)
axes[1].set_title("F7 -- saccade artifacts (step functions)")
axes[1].set_ylabel("uV")

axes[2].plot(t_sec, raw.get_data(picks="T7")[0, t_plot] * 1e6)
axes[2].set_title("T7 -- EMG artifacts (high-frequency bursts)")
axes[2].set_ylabel("uV")

axes[3].plot(t_sec, raw.get_data(picks="Cz")[0, t_plot] * 1e6)
axes[3].set_title("Cz -- ECG artifacts (periodic sharp peaks at ~1 Hz)")
axes[3].set_ylabel("uV")
axes[3].set_xlabel("Time (s)")

plt.tight_layout()
plt.show()

print("Four artifact types injected and plotted.")
print(f"  Blinks: {len(blink_times)} events on Fp1/Fp2")
print(f"  Saccades: {len(saccade_times)} events on F7/F8")
print(f"  EMG bursts: {len(emg_times)} events on T7/T8")
print(f"  ECG peaks: {len(ecg_times)} events on all channels")

You should see four distinct patterns. Fp1 has large, slow bumps (blinks). F7 shows sudden voltage steps (saccades). T7 has short bursts of high-frequency noise (EMG). Cz shows small, sharp spikes repeating every second (ECG). In real data you would rarely see artifacts this cleanly separated, but this is what each type looks like in isolation.

Exercise 7: Annotation-based artifact rejection

Create a Raw object, add Annotations for three bad segments (different types: “bad_blink”, “bad_movement”, “bad_muscle”). Create epochs and show that epochs overlapping with bad annotations are automatically excluded. Report kept vs dropped.

TipHint

Use mne.Annotations(onset, duration, description) to create annotations, then assign them with raw.set_annotations(). Any annotation whose description starts with “bad” or “BAD” will cause MNE to reject overlapping epochs automatically. Create fixed-length events and build Epochs with reject_by_annotation=True (this is the default). Check epochs.drop_log to see which epochs were dropped and why.

NoteSolution 
import numpy as np
import mne

sfreq = 500
duration = 30
times = np.arange(0, duration, 1 / sfreq)
n_samples = len(times)

ch_names = ["Fp1", "Fp2", "C3", "C4", "O1", "O2"]
n_channels = len(ch_names)
info = mne.create_info(ch_names=ch_names, sfreq=sfreq, ch_types="eeg")
data = np.random.randn(n_channels, n_samples) * 10e-6

raw = mne.io.RawArray(data, info)

# Add three bad annotations of different types
annotations = mne.Annotations(
    onset=[3.0, 12.5, 22.0],
    duration=[1.0, 2.0, 0.5],
    description=["bad_blink", "bad_movement", "bad_muscle"]
)
raw.set_annotations(annotations)

print("Annotations added:")
for ann in raw.annotations:
    print(f"  {ann['description']}: onset={ann['onset']:.1f} s, "
          f"duration={ann['duration']:.1f} s")

# Create 2-second epochs
events = mne.make_fixed_length_events(raw, duration=2.0)
epochs = mne.Epochs(
    raw, events,
    tmin=0, tmax=2.0,
    baseline=None,
    reject_by_annotation=True,  # this is the default
    preload=True
)

n_total = len(events)
n_kept = len(epochs)
n_dropped = n_total - n_kept

print(f"\nTotal epochs created: {n_total}")
print(f"Epochs kept: {n_kept}")
print(f"Epochs dropped: {n_dropped}")

# Show the drop log
print("\nDrop log (reason for each dropped epoch):")
for i, log in enumerate(epochs.drop_log):
    if len(log) > 0:

Exercise 15: Build an artifact summary report

Write a function that takes an Epochs object (with drop_log populated) and returns a summary: total epochs, epochs kept, epochs dropped, percentage dropped, and the channels most frequently responsible for rejection. Test on simulated data with artifacts concentrated on specific channels.

TipHint

The epochs.drop_log is a tuple of tuples. Each entry is empty (epoch kept) or contains the names of channels that caused the rejection. Loop through the drop log, count how often each channel name appears, and sort by frequency. Use collections.Counter for convenience.

NoteSolution 
import numpy as np
import mne
from collections import Counter


def artifact_summary(epochs):
    """Produce a summary report of epoch rejections.

    Parameters
    ----------
    epochs : mne.Epochs
        Epochs object with drop_log populated (must have been created
        with preload=True and a reject parameter).

    Returns
    -------
    report : dict
        Summary with keys: total, kept, dropped, pct_dropped,
        channel_counts (Counter of channel names causing rejections).
    """
    drop_log = epochs.drop_log
    total = len(drop_log)
    kept = sum(1 for entry in drop_log if len(entry) == 0)
    dropped = total - kept

    # Count which channels caused rejections
    channel_counts = Counter()
    for entry in drop_log:
        for ch_name in entry:
            if ch_name not in ("IGNORED",):
                channel_counts[ch_name] += 1

    report = {
        "total": total,
        "kept": kept,
        "dropped": dropped,
        "pct_dropped": 100 * dropped / total if total > 0 else 0,
        "channel_counts": channel_counts,
    }
    return report


def print_report(report):
    """Print a formatted artifact summary."""
    print("=== Artifact Rejection Summary ===")
    print(f"Total epochs:    {report['total']}")
    print(f"Epochs kept:     {report['kept']}")
    print(f"Epochs dropped:  {report['dropped']}")
    print(f"Percentage dropped: {report['pct_dropped']:.1f}%")

    if report["channel_counts"]:
        print("\nChannels most often responsible for rejection:")
        for ch, count in report["channel_counts"].most_common():
            print(f"  {ch}: {count} times")
    else:
        print("\nNo channels caused rejections.")

Exercise 17: Simulate and detect a saccade artifact

With a strong, well-defined artifact like blinks on clean simulated data, you should see correlations very close to 1.0 across runs. On noisier or more ambiguous data, the correlations may drop. This is why it is good practice to set random_state to a fixed value for reproducibility when reporting results, and to check stability if you are not sure whether ICA is giving reliable results for your dataset.

Exercise 20: Build a combined artifact rejection pipeline

Write a function that: (1) applies amplitude rejection to remove the worst epochs, (2) fits ICA on the surviving data, (3) identifies and removes blink and cardiac components, (4) applies ICA to the full epoch set. Compare the data quality before and after the full pipeline by computing the mean PSD.

TipHint

The trick is to fit ICA on clean(er) data (after rejecting the worst epochs) but then apply the ICA solution to all epochs (including those that were borderline). First create epochs with a strict rejection threshold to get a clean subset. Fit ICA on that subset. Find the bad components. Then go back, create epochs from the original data with a more lenient threshold (or no threshold), and apply ica.apply() to those epochs. Compare the PSD of the original vs cleaned epochs.

import numpy as np
import mne
from mne.preprocessing import ICA
import matplotlib.pyplot as plt


def combined_pipeline(raw, sfreq, strict_thresh=80e-6, lenient_thresh=200e-6):
    """Run a combined amplitude-rejection + ICA cleaning pipeline.

    Parameters
    ----------
    raw : mne.io.Raw
        Raw data (with EEG and optionally ECG channels).
    sfreq : float
        Sampling frequency.
    strict_thresh : float
        Strict threshold (V) for selecting clean epochs for ICA fitting.
    lenient_thresh : float
        Lenient threshold (V) for the final epoch set.

    Returns
    -------
    epochs_before : mne.Epochs
        Epochs before ICA cleaning (lenient rejection only).
    epochs_after : mne.Epochs
        Epochs after ICA cleaning.
    ica : ICA
        The fitted ICA object.
    """
    # Step 1: Create events
    events = mne.make_fixed_length_events(raw, duration=2.0)

    # Step 2: Create strictly rejected epochs for ICA fitting
    epochs_strict = mne.Epochs(
        raw, events, tmin=0, tmax=2.0, baseline=None,
        reject=dict(eeg=strict_thresh), preload=True
    )
    n_strict = len(epochs_strict)
    print(f"Step 1: Strict rejection ({strict_thresh * 1e6:.0f} uV) "
          f"kept {n_strict}/{len(events)} epochs for ICA fitting")

    # Step 3: Fit ICA on the clean subset
    ica = ICA(n_components=15, random_state=42)
    ica.fit(epochs_strict)
    print(f"Step 2: ICA fitted with {ica.n_components_} components")

    # Step 4: Find bad components
    excluded = []

    # Find blink components
    blink_idx, _ = ica.find_bads_eog(raw, ch_name="Fp1", threshold=2.0)
    excluded.extend(blink_idx)
    print(f"Step 3a: Blink components found: {blink_idx}")

    # Find ECG components (if ECG channel exists)
    if "ECG" in raw.ch_names:
        ecg_idx, _ = ica.find_bads_ecg(raw, ch_name="ECG", threshold=0.5)
        excluded.extend(ecg_idx)
        print(f"Step 3b: ECG components found: {ecg_idx}")

    ica.exclude = list(set(excluded))
    print(f"Step 3: Total components to exclude: {ica.exclude}")

    # Step 5: Create lenient epochs from original data (before ICA)
    raw_for_epochs = raw.copy()
    epochs_before = mne.Epochs(
        raw_for_epochs, events, tmin=0, tmax=2.0, baseline=None,
        reject=dict(eeg=lenient_thresh), preload=True
    )
    print(f"Step 4: Lenient rejection ({lenient_thresh * 1e6:.0f} uV) "
          f"kept {len(epochs_before)}/{len(events)} epochs")

    # Step 6: Apply ICA to the lenient epochs
    epochs_after = epochs_before.copy()
    ica.apply(epochs_after)
    print(f"Step 5: ICA applied to {len(epochs_after)} epochs")

    return epochs_before, epochs_after, ica

This pipeline combines the strengths of both approaches. Amplitude rejection removes the worst epochs first, giving ICA cleaner data to work with (ICA performs poorly when the training data contains extreme artifacts). Then ICA handles the subtler, systematic artifacts (blinks, heartbeats) that repeat across epochs. The final result should show reduced low-frequency power (from removing blinks) and reduced sharp-peak artifacts (from removing ECG). In a real analysis, you would run exactly this kind of pipeline, possibly with autoreject or a similar tool for the threshold-selection step.
