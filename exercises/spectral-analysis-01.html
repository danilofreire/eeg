These exercises go with Module 4: Spectral and time-frequency analysis. They cover the practical side of frequency-domain analysis: computing power spectral density, extracting power in the standard EEG bands, tracking how spectral content changes over time, and comparing spectral features between groups. All exercises use simulated data so you always know the ground truth.

Exercise 1: Compute PSD with Welch’s method and identify peaks

Create a simulated signal that combines a 10 Hz alpha oscillation, a 22 Hz beta oscillation, and pink (1/f) background noise. Compute the power spectral density using scipy.signal.welch and plot it. Identify the two spectral peaks and label them on the plot.

TipHint

Generate pink noise by filtering white noise in the frequency domain: take the FFT, scale each frequency bin by \(1/\sqrt{f}\) (to get a \(1/f\) power spectrum), then take the inverse FFT. Add two sine waves at 10 Hz and 22 Hz with different amplitudes (alpha is usually stronger than beta). For Welch’s method, use scipy.signal.welch(signal, fs=sfreq, nperseg=512). Plot on a log scale (ax.semilogy()) so both peaks are visible above the 1/f background.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

rng = np.random.default_rng(42)

sfreq = 256
duration = 30
n_samples = sfreq * duration
times = np.arange(n_samples) / sfreq

# Generate pink noise (1/f background)
white = rng.standard_normal(n_samples)
freqs_fft = np.fft.rfftfreq(n_samples, d=1 / sfreq)
freqs_fft[0] = 1  # avoid division by zero
pink_filter = 1 / np.sqrt(freqs_fft)
pink = np.fft.irfft(np.fft.rfft(white) * pink_filter, n=n_samples)
pink = pink / pink.std()

# Add oscillatory components
alpha = 1.5 * np.sin(2 * np.pi * 10 * times)   # 10 Hz alpha
beta = 0.7 * np.sin(2 * np.pi * 22 * times)    # 22 Hz beta (weaker)
eeg = pink + alpha + beta

# Compute PSD with Welch's method
freqs_psd, psd = signal.welch(eeg, fs=sfreq, nperseg=512, noverlap=256)

# Plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.semilogy(freqs_psd, psd, linewidth=1.2, color="#2c3e50")
ax.axvline(10, color="#e74c3c", linestyle="--", alpha=0.7, label="Alpha (10 Hz)")
ax.axvline(22, color="#3498db", linestyle="--", alpha=0.7, label="Beta (22 Hz)")
ax.set_xlabel("Frequency (Hz)")
ax.set_ylabel("Power spectral density")
ax.set_title("PSD of simulated EEG (alpha + beta + pink noise)")
ax.set_xlim(0, 50)
ax.legend()
plt.tight_layout()
plt.show()

You should see the characteristic 1/f slope of the pink noise with two peaks rising above it: a taller one at 10 Hz and a shorter one at 22 Hz. The log scale on the y-axis makes both peaks easy to spot, even though the alpha component has roughly twice the amplitude of the beta component.

Exercise 2: Compute band power and relative power for the five standard bands

Create a simulated signal with a strong alpha peak (similar to Exercise 1) and compute the absolute power in each of the five standard EEG frequency bands: delta (0.5–4 Hz), theta (4–8 Hz), alpha (8–13 Hz), beta (13–30 Hz), and gamma (30–45 Hz). Then compute the relative power of each band as a percentage of the total power across all bands. Print a table of results.

TipHint

After computing the PSD with scipy.signal.welch, use np.trapz() (or scipy.integrate.trapezoid()) to integrate the PSD over each frequency range. To select the right frequencies, create a boolean mask: mask = (freqs >= f_low) & (freqs < f_high). Relative power is simply band_power / total_power * 100. Total power is the sum of all five bands (or the integral over the full range).

NoteSolution 
import numpy as np
from scipy import signal

rng = np.random.default_rng(42)

sfreq = 256
duration = 60
n_samples = sfreq * duration
times = np.arange(n_samples) / sfreq

# Signal: pink noise + alpha oscillation + some beta
white = rng.standard_normal(n_samples)
freqs_fft = np.fft.rfftfreq(n_samples, d=1 / sfreq)
freqs_fft[0] = 1
pink_filter = 1 / np.sqrt(freqs_fft)
pink = np.fft.irfft(np.fft.rfft(white) * pink_filter, n=n_samples)
pink = pink / pink.std()

alpha = 2.0 * np.sin(2 * np.pi * 10 * times)
beta = 0.5 * np.sin(2 * np.pi * 20 * times)
eeg = pink + alpha + beta

# Compute PSD
freqs_psd, psd = signal.welch(eeg, fs=sfreq, nperseg=1024, noverlap=512)

# Define the standard EEG bands
bands = {
    "Delta": (0.5, 4),
    "Theta": (4, 8),
    "Alpha": (8, 13),
    "Beta":  (13, 30),
    "Gamma": (30, 45),
}

# Compute absolute band power by integrating the PSD
band_powers = {}
for name, (f_low, f_high) in bands.items():
    mask = (freqs_psd >= f_low) & (freqs_psd < f_high)
    band_powers[name] = np.trapz(psd[mask], freqs_psd[mask])

total_power = sum(band_powers.values())

# Print the results
print(f"{'Band':<8} {'Abs. power':>12} {'Rel. power (%)':>15}")
print("-" * 38)
for name, power in band_powers.items():
    rel = power / total_power * 100
    print(f"{name:<8} {power:>12.4f} {rel:>14.1f}%")
print("-" * 38)
print(f"{'Total':<8} {total_power:>12.4f} {'100.0%':>15}")

Alpha should dominate because we injected a strong 10 Hz oscillation. Delta will also have a fair share because the 1/f pink noise concentrates power at low frequencies. Beta and gamma should be low, and theta will be somewhere in between.

Exercise 3: Visualise time-varying alpha power with a spectrogram

Create a 20-second signal where alpha power is strong in the first 10 seconds and weak (or absent) in the last 10 seconds, simulating an “eyes closed then eyes open” transition. Use scipy.signal.spectrogram to compute and plot the spectrogram. Verify that the alpha band (8–13 Hz) shows a clear drop at the midpoint.

TipHint

Build the signal in two halves: for the first half, add a large-amplitude 10 Hz sine wave to the noise; for the second half, use noise only (or add a much smaller sine wave). scipy.signal.spectrogram returns (frequencies, times, Sxx) where Sxx[i, j] is the power at frequencies[i] and times[j]. Plot it with ax.pcolormesh(times, frequencies, 10 * np.log10(Sxx)) for a dB scale. Use nperseg=256 and noverlap=128 for reasonable time-frequency resolution at 256 Hz sampling rate.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

rng = np.random.default_rng(42)

sfreq = 256
duration = 20
n_samples = sfreq * duration
times = np.arange(n_samples) / sfreq
midpoint = n_samples // 2

# Background noise for the full signal
noise = rng.standard_normal(n_samples) * 0.5

# Alpha oscillation: strong in first half, absent in second half
alpha = np.zeros(n_samples)
alpha[:midpoint] = 2.0 * np.sin(2 * np.pi * 10 * times[:midpoint])

eeg = noise + alpha

# Compute the spectrogram
freqs_spec, times_spec, Sxx = signal.spectrogram(
    eeg, fs=sfreq, nperseg=256, noverlap=128
)

# Plot
fig, axes = plt.subplots(2, 1, figsize=(10, 7))

# Top panel: time-domain signal
ax = axes[0]
ax.plot(times, eeg, linewidth=0.3, color="#2c3e50")
ax.axvline(10, color="#e74c3c", linestyle="--", alpha=0.7, label="Transition")
ax.set_xlabel("Time (s)")
ax.set_ylabel("Amplitude (a.u.)")
ax.set_title("Simulated EEG: strong alpha (0-10 s), then noise only (10-20 s)")
ax.legend()

# Bottom panel: spectrogram
ax = axes[1]
mesh = ax.pcolormesh(
    times_spec, freqs_spec, 10 * np.log10(Sxx),
    shading="gouraud", cmap="viridis"
)
ax.set_ylim(0, 40)
ax.axhline(8, color="white", linestyle="--", linewidth=0.7, alpha=0.7)
ax.axhline(13, color="white", linestyle="--", linewidth=0.7, alpha=0.7)
ax.set_xlabel("Time (s)")
ax.set_ylabel("Frequency (Hz)")
ax.set_title("Spectrogram (dB)")
fig.colorbar(mesh, ax=ax, label="Power (dB)")

plt.tight_layout()
plt.show()

The spectrogram should show a bright horizontal band between 8 and 13 Hz in the first half of the recording, which disappears abruptly at the 10-second mark. The white dashed lines mark the alpha band boundaries. This is the spectral signature of alpha desynchronisation, which is what happens in real EEG when someone opens their eyes.

Exercise 4: Compare PSD between two simulated groups

Simulate two “groups” of subjects. Group A has a strong alpha peak (10 Hz); Group B has a weak alpha peak. Generate 15 subjects per group, compute the alpha band power for each, and run an independent-samples t-test to determine whether the groups differ significantly. Plot the group-averaged PSDs and a box plot of alpha band power.

TipHint

For each subject, generate a fresh noise signal and add a 10 Hz sine wave with a group-specific amplitude (e.g., amplitude = 2.0 for Group A, amplitude = 0.5 for Group B, plus some between-subject variability drawn from a normal distribution). Compute the PSD for each subject with scipy.signal.welch, then integrate across the alpha band (8–13 Hz) to get one band-power value per subject. Use scipy.stats.ttest_ind for the t-test.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal
from scipy.stats import ttest_ind

rng = np.random.default_rng(42)

sfreq = 256
duration = 60
n_samples = sfreq * duration
times = np.arange(n_samples) / sfreq
n_subjects = 15

def simulate_subject(alpha_amp, rng):
    """Simulate one subject's EEG and return alpha band power."""
    # Pink noise
    white = rng.standard_normal(n_samples)
    freqs_fft = np.fft.rfftfreq(n_samples, d=1 / sfreq)
    freqs_fft[0] = 1
    pink_filter = 1 / np.sqrt(freqs_fft)
    pink = np.fft.irfft(np.fft.rfft(white) * pink_filter, n=n_samples)
    pink = pink / pink.std()

    # Add alpha oscillation
    eeg = pink + alpha_amp * np.sin(2 * np.pi * 10 * times)

    # Compute PSD
    freqs_psd, psd = signal.welch(eeg, fs=sfreq, nperseg=1024, noverlap=512)
    return freqs_psd, psd

# Simulate both groups
alpha_powers_a = []
alpha_powers_b = []
psds_a = []
psds_b = []

for i in range(n_subjects):
    # Group A: strong alpha (mean amplitude 2.0, sd 0.3)
    amp_a = rng.normal(2.0, 0.3)
    freqs_psd, psd_a = simulate_subject(amp_a, rng)
    psds_a.append(psd_a)
    mask_alpha = (freqs_psd >= 8) & (freqs_psd < 13)
    alpha_powers_a.append(np.trapz(psd_a[mask_alpha], freqs_psd[mask_alpha]))

    # Group B: weak alpha (mean amplitude 0.5, sd 0.2)
    amp_b = rng.normal(0.5, 0.2)
    freqs_psd, psd_b = simulate_subject(amp_b, rng)
    psds_b.append(psd_b)
    alpha_powers_b.append(np.trapz(psd_b[mask_alpha], freqs_psd[mask_alpha]))

alpha_powers_a = np.array(alpha_powers_a)
alpha_powers_b = np.array(alpha_powers_b)

# T-test
t_stat, p_value = ttest_ind(alpha_powers_a, alpha_powers_b)
print(f"Group A alpha power: mean = {alpha_powers_a.mean():.3f}, "
      f"sd = {alpha_powers_a.std():.3f}")
print(f"Group B alpha power: mean = {alpha_powers_b.mean():.3f}, "
      f"sd = {alpha_powers_b.std():.3f}")
print(f"t-test: t = {t_stat:.3f}, p = {p_value:.6f}")

# Plot
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# Left: group-averaged PSDs
ax = axes[0]
mean_psd_a = np.mean(psds_a, axis=0)
mean_psd_b = np.mean(psds_b, axis=0)
ax.semilogy(freqs_psd, mean_psd_a, label="Group A (strong alpha)",
            color="#e74c3c", linewidth=1.5)
ax.semilogy(freqs_psd, mean_psd_b, label="Group B (weak alpha)",
            color="#3498db", linewidth=1.5)
ax.axvspan(8, 13, alpha=0.15, color="orange", label="Alpha band")
ax.set_xlabel("Frequency (Hz)")
ax.set_ylabel("PSD")
ax.set_xlim(0, 45)
ax.set_title("Group-averaged PSD")
ax.legend(fontsize=9)

# Right: box plot of alpha band power
ax = axes[1]
bp = ax.boxplot(
    [alpha_powers_a, alpha_powers_b],
    labels=["Group A\n(strong alpha)", "Group B\n(weak alpha)"],
    patch_artist=True
)
bp["boxes"][0].set_facecolor("#e74c3c")
bp["boxes"][1].set_facecolor("#3498db")
for box in bp["boxes"]:
    box.set_alpha(0.5)
ax.set_ylabel("Alpha band power (8-13 Hz)")
ax.set_title(f"Alpha power comparison (p = {p_value:.2e})")

plt.tight_layout()
plt.show()

You should see a highly significant p-value (well below 0.05) because the two groups have very different alpha amplitudes by design. The PSD plot will show Group A with a tall alpha peak and Group B with a much smaller one. In real studies, the effect sizes are usually much smaller, but the analysis workflow is the same.

Exercise 5: Build a reusable band-power function

Write a function compute_band_powers(data, sfreq) that takes a 2D NumPy array (channels x samples) and a sampling rate, and returns a dictionary where each key is a band name ("delta", "theta", "alpha", "beta", "gamma") and each value is a 1D array of band powers (one value per channel). Test it on a simulated multi-channel signal and print the results.

TipHint

Inside the function, loop over channels and compute the PSD for each one using scipy.signal.welch. Then, for each band, integrate the PSD between the band’s frequency limits using np.trapz. Return a dictionary of arrays. You could also compute the PSD for all channels at once by passing a 2D array to scipy.signal.welch (it operates along the last axis by default, so you may need to handle the axis parameter).

NoteSolution 
import numpy as np
from scipy import signal


BANDS = {
    "delta": (0.5, 4),
    "theta": (4, 8),
    "alpha": (8, 13),
    "beta":  (13, 30),
    "gamma": (30, 45),
}


def compute_band_powers(data, sfreq, nperseg=1024):
    """Compute band power for each channel in the standard EEG bands.

    Parameters
    ----------
    data : numpy.ndarray
        2D array of shape (n_channels, n_samples).
    sfreq : float
        Sampling frequency in Hz.
    nperseg : int
        Number of samples per Welch segment (controls frequency resolution).

    Returns
    -------
    band_powers : dict
        Keys are band names ('delta', 'theta', 'alpha', 'beta', 'gamma').
        Values are 1D arrays of shape (n_channels,) with the band power
        for each channel.
    """
    n_channels = data.shape[0]
    band_powers = {name: np.zeros(n_channels) for name in BANDS}

    for ch in range(n_channels):
        freqs_psd, psd = signal.welch(
            data[ch], fs=sfreq, nperseg=nperseg, noverlap=nperseg // 2
        )
        for name, (f_low, f_high) in BANDS.items():
            mask = (freqs_psd >= f_low) & (freqs_psd < f_high)
            band_powers[name][ch] = np.trapz(psd[mask], freqs_psd[mask])

    return band_powers


# ── Test the function ──────────────────────────────────────────
rng = np.random.default_rng(42)

sfreq = 256
duration = 30
n_samples = sfreq * duration
times = np.arange(n_samples) / sfreq

ch_names = ["Fp1", "Fp2", "C3", "C4", "O1", "O2", "Oz", "Pz"]
n_channels = len(ch_names)

# Simulate data: noise + alpha in occipital channels + beta in central
data = rng.standard_normal((n_channels, n_samples)) * 0.5

# Add alpha to O1, O2, Oz
for ch_name in ["O1", "O2", "Oz"]:
    idx = ch_names.index(ch_name)
    data[idx] += 2.0 * np.sin(2 * np.pi * 10 * times)

# Add beta to C3, C4
for ch_name in ["C3", "C4"]:
    idx = ch_names.index(ch_name)
    data[idx] += 1.0 * np.sin(2 * np.pi * 20 * times)

# Compute band powers
bp = compute_band_powers(data, sfreq)

# Print the results
print(f"{'Channel':<8}", end="")
for name in BANDS:
    print(f"{name:>10}", end="")
print()
print("-" * 58)
for ch in range(n_channels):
    print(f"{ch_names[ch]:<8}", end="")
    for name in BANDS:
        print(f"{bp[name][ch]:>10.4f}", end="")
    print()

The occipital channels (O1, O2, Oz) should show high alpha power relative to the others. The central channels (C3, C4) should show higher beta power. Frontal channels (Fp1, Fp2) and Pz will only have noise, so their band powers should be roughly uniform and much lower.

Exercise 6: Effect of window length on PSD resolution

Create a signal that combines two close sine waves at 9 Hz and 11 Hz (plus some noise). Compute the PSD with Welch’s method four times, using nperseg values of 256, 512, 1024, and 2048. Plot all four PSDs on the same figure. You should see that short windows blur the two peaks into one, while longer windows can separate them. This demonstrates the trade-off between frequency resolution and the number of averaged segments.

TipHint

Frequency resolution is approximately sfreq / nperseg. With sfreq = 256 and nperseg = 256, the resolution is 1 Hz, which is not enough to separate peaks that are only 2 Hz apart (you need better than 2 Hz resolution, but the spectral leakage from a 1 Hz bin width will merge them). With nperseg = 2048, resolution is 0.125 Hz, which easily resolves two peaks 2 Hz apart. Use subplots or overlay the four PSDs with a legend.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

rng = np.random.default_rng(42)

sfreq = 256
duration = 30
n_samples = sfreq * duration
times = np.arange(n_samples) / sfreq

# Two close peaks at 9 Hz and 11 Hz, plus noise
sig = (1.5 * np.sin(2 * np.pi * 9 * times)
       + 1.5 * np.sin(2 * np.pi * 11 * times)
       + rng.standard_normal(n_samples) * 0.8)

# Compute PSD with different window lengths
nperseg_values = [256, 512, 1024, 2048]

fig, axes = plt.subplots(2, 2, figsize=(12, 8), sharex=True, sharey=True)
axes = axes.ravel()

for ax, nperseg in zip(axes, nperseg_values):
    freqs_psd, psd = signal.welch(sig, fs=sfreq, nperseg=nperseg,
                                  noverlap=nperseg // 2)
    freq_res = sfreq / nperseg
    ax.plot(freqs_psd, psd, linewidth=1.2, color="#2c3e50")
    ax.axvline(9, color="#e74c3c", linestyle="--", alpha=0.6, linewidth=0.8)
    ax.axvline(11, color="#3498db", linestyle="--", alpha=0.6, linewidth=0.8)
    ax.set_xlim(4, 18)
    ax.set_title(f"nperseg = {nperseg}  (resolution = {freq_res:.2f} Hz)")
    ax.set_xlabel("Frequency (Hz)")
    ax.set_ylabel("PSD")

fig.suptitle("Effect of window length on frequency resolution", fontsize=13)
plt.tight_layout()
plt.show()

# Print frequency resolution for each setting
for nperseg in nperseg_values:
    print(f"nperseg = {nperseg:>5d}  ->  freq. resolution = "
          f"{sfreq / nperseg:.3f} Hz")

With nperseg = 256 (1 Hz resolution), the two peaks merge into a single broad hump centred around 10 Hz. At nperseg = 512 (0.5 Hz), you may start to see a hint of two peaks. At nperseg = 1024 and nperseg = 2048, the two peaks at 9 Hz and 11 Hz are clearly separated. The cost of using longer windows is that you get fewer segments to average, so the PSD estimate is noisier.

Exercise 7: Find the individual alpha frequency (IAF)

Create a simulated EEG signal where the alpha peak sits at 10.5 Hz rather than exactly 10 Hz (this is realistic, since the individual alpha frequency varies from person to person, typically between 8 and 13 Hz). Compute the PSD with Welch’s method and then find the exact peak frequency in the 8–13 Hz range by locating the frequency bin with the maximum power. Print the detected IAF and compare it with the true value.

TipHint

Generate pink noise and add a sine wave at 10.5 Hz. After computing the PSD, create a boolean mask for the alpha range ((freqs >= 8) & (freqs <= 13)), then use np.argmax(psd[mask]) to find the index of the peak within that range. The corresponding frequency is freqs[mask][peak_index]. Use a long nperseg (e.g., 2048) to get enough frequency resolution to distinguish 10.5 Hz from 10.0 Hz.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

rng = np.random.default_rng(42)

sfreq = 256
duration = 60
n_samples = sfreq * duration
times = np.arange(n_samples) / sfreq
true_iaf = 10.5  # Hz

# Pink noise background
white = rng.standard_normal(n_samples)
freqs_fft = np.fft.rfftfreq(n_samples, d=1 / sfreq)
freqs_fft[0] = 1  # avoid division by zero
pink_filter = 1 / np.sqrt(freqs_fft)
pink = np.fft.irfft(np.fft.rfft(white) * pink_filter, n=n_samples)
pink = pink / pink.std()

# Add alpha oscillation at 10.5 Hz
alpha = 2.0 * np.sin(2 * np.pi * true_iaf * times)
eeg = pink + alpha

# Compute PSD with good frequency resolution
freqs_psd, psd = signal.welch(eeg, fs=sfreq, nperseg=2048, noverlap=1024)

# Find peak in the alpha range
alpha_mask = (freqs_psd >= 8) & (freqs_psd <= 13)
alpha_freqs = freqs_psd[alpha_mask]
alpha_psd = psd[alpha_mask]
peak_idx = np.argmax(alpha_psd)
detected_iaf = alpha_freqs[peak_idx]

print(f"True IAF:     {true_iaf:.2f} Hz")
print(f"Detected IAF: {detected_iaf:.2f} Hz")
print(f"Error:        {abs(detected_iaf - true_iaf):.3f} Hz")

# Plot
fig, ax = plt.subplots(figsize=(8, 4))
ax.semilogy(freqs_psd, psd, linewidth=1.2, color="#2c3e50")
ax.axvline(detected_iaf, color="#e74c3c", linestyle="--",
           label=f"Detected IAF = {detected_iaf:.2f} Hz")
ax.axvspan(8, 13, alpha=0.15, color="orange", label="Alpha band")
ax.set_xlim(0, 40)
ax.set_xlabel("Frequency (Hz)")
ax.set_ylabel("PSD")
ax.set_title("Individual alpha frequency detection")
ax.legend()
plt.tight_layout()
plt.show()

The detected IAF should be very close to 10.5 Hz (the error depends on the frequency resolution, which is 256 / 2048 = 0.125 Hz here). In real EEG data, researchers use the IAF to define subject-specific alpha bands (e.g., IAF +/- 2 Hz) rather than using the fixed 8–13 Hz range for everyone.

Exercise 8: Estimate the 1/f aperiodic slope

Create pink noise with a known 1/f exponent. In the frequency domain, pink noise has a power spectrum that falls off as \(1/f^\beta\), where \(\beta = 1\) for classical pink noise. Compute the PSD, take the logarithm of both the frequencies and the PSD values, and fit a straight line using np.polyfit. The slope of that line is your estimate of \(-\beta\). Compare it with the known ground truth. This is the basis of spectral parameterisation methods like FOOOF/specparam.

TipHint

To generate noise with a specific exponent \(\beta\), take white noise, compute its FFT, multiply each frequency bin by \(f^{-\beta/2}\) (since power is amplitude squared), then take the inverse FFT. Create epoched data that simulates alpha desynchronisation after a visual stimulus. Before time zero (baseline), alpha power is strong. After time zero, alpha power drops. TipHint

For each epoch, create a signal where the alpha amplitude is high before t = 0 and low after t = 0 (e.g., multiply the alpha sine wave by an envelope that steps down at time zero). NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

rng = np.random.default_rng(42)

sfreq = 256
epoch_duration = 3.0  # seconds: -1 to +2 s relative to event
n_samples_epoch = int(sfreq * epoch_duration)
times = np.linspace(-1, 2, n_samples_epoch, endpoint=False)
n_epochs = 40

# Create alpha envelope: full amplitude before t=0, reduced after
alpha_freq = 10  # Hz
baseline_amp = 2.0
active_amp = 0.5  # alpha drops after stimulus

epochs = np.zeros((n_epochs, n_samples_epoch))
for i in range(n_epochs):
    # Alpha oscillation with time-varying amplitude
    envelope = np.where(times < 0, baseline_amp, active_amp)
    # Add gradual transition (50 ms ramp)
    ramp_samples = int(0.05 * sfreq)
    zero_idx = np.argmin(np.abs(times))
    ramp = np.linspace(baseline_amp, active_amp, ramp_samples)
    envelope[zero_idx:zero_idx + ramp_samples] = ramp

    alpha = envelope * np.sin(2 * np.pi * alpha_freq * times
                              + rng.uniform(0, 2 * np.pi))
    noise = rng.standard_normal(n_samples_epoch) * 0.8

sos = signal.butter(4, [8, 13], btype="band", fs=sfreq, output="sos")

mean_power = inst_power.mean(axis=0)

kernel_size = int(0.1 * sfreq)
kernel = np.ones(kernel_size) / kernel_size
smoothed_power = np.convolve(mean_power, kernel, mode="same")

baseline_power = smoothed_power[baseline_mask].mean()

# Quantify
active_mask = (times >= 0.5) & (times < 1.5)
mean_erd = erd_percent[active_mask].mean()
print(f"Baseline alpha power: {baseline_power:.4f}")
print(f"Mean ERD (0.5-1.5 s): {mean_erd:.1f}%")

# Plot
fig, axes = plt.subplots(2, 1, figsize=(10, 7))

ax = axes[0]
ax.plot(times, smoothed_power, linewidth=1.5, color="#2c3e50")
ax.axvline(0, color="#e74c3c", linestyle="--", alpha=0.7, label="Stimulus")
ax.axhline(baseline_power, color="grey", linestyle=":", alpha=0.6,
           label="Baseline level")
ax.set_xlabel("Time (s)")
ax.set_ylabel("Alpha power")
ax.set_title(f"Alpha power time course (n = {n_epochs} epochs)")
ax.legend()

ax = axes[1]
ax.plot(times, erd_percent, linewidth=1.5, color="#8e44ad")
ax.axvline(0, color="#e74c3c", linestyle="--", alpha=0.7, label="Stimulus")
ax.axhline(0, color="grey", linestyle=":", alpha=0.6)
ax.fill_between(times, erd_percent, 0, where=erd_percent < 0,
                alpha=0.3, color="#8e44ad", label="ERD")
ax.set_xlabel("Time (s)")
ax.set_ylabel("ERD (%)")
ax.set_title(f"Event-related desynchronisation (mean ERD = {mean_erd:.1f}%)")
ax.legend()

plt.tight_layout()

Exercise 13: Compute ERSP with baseline correction

Create epoched data where the spectral content changes over time (strong alpha before the event, strong beta after the event). Compute the spectrogram for each epoch, average across epochs, and apply baseline correction in both dB and percent-change modes. Plot both to see how they differ in scale and interpretability.

TipHint

For each epoch, compute the spectrogram with scipy.signal.spectrogram (use a short nperseg for good time resolution, e.g., 128 samples). Average the spectrograms across all epochs. For baseline correction, take the mean power in each frequency bin during the pre-stimulus interval. In dB mode: 10 * log10(power / baseline). In percent-change mode: (power - baseline) / baseline * 100. Broadcast the baseline array across the time dimension.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

rng = np.random.default_rng(42)

sfreq = 256
epoch_duration = 3.0  # -1 to +2 s
n_samples_epoch = int(sfreq * epoch_duration)
times_epoch = np.linspace(-1, 2, n_samples_epoch, endpoint=False)
n_epochs = 50

# Generate epochs: alpha before event, beta after event
all_Sxx = []

for i in range(n_epochs):
    noise = rng.standard_normal(n_samples_epoch) * 0.5

    # Alpha (10 Hz) in baseline, fading out after event
    alpha_env = np.where(times_epoch < 0, 1.5, 0.3)
    alpha = alpha_env * np.sin(2 * np.pi * 10 * times_epoch
                               + rng.uniform(0, 2 * np.pi))

    # Beta (22 Hz) appears after event
    beta_env = np.where(times_epoch >= 0.2, 1.2, 0.2)
    beta = beta_env * np.sin(2 * np.pi * 22 * times_epoch
                             + rng.uniform(0, 2 * np.pi))

    epoch = noise + alpha + beta

    freqs_s, times_s, Sxx = signal.spectrogram(
        epoch, fs=sfreq, nperseg=128, noverlap=112

# Avoid division by zero
baseline_power = np.maximum(baseline_power, 1e-10)

# dB correction
ersp_db = 10 * np.log10(mean_Sxx / baseline_power)

# Percent-change correction
ersp_pct = (mean_Sxx - baseline_power) / baseline_power * 100

fig.colorbar(mesh, ax=ax, label="Power (dB re baseline)")

ax = axes[1]
vmax_pct = np.percentile(np.abs(ersp_pct), 95)
mesh = ax.pcolormesh(times_s_actual, freqs_s, ersp_pct,
                     shading="gouraud", cmap="RdBu_r",
                     vmin=-vmax_pct, vmax=vmax_pct)
ax.axvline(0, color="black", linestyle="--", linewidth=0.8)
ax.set_ylim(0, 40)
ax.set_xlabel("Time (s)")
ax.set_ylabel("Frequency (Hz)")
ax.set_title("ERSP (% change)")
fig.colorbar(mesh, ax=ax, label="Power change (%)")

plt.tight_layout()
plt.show()

print("Blue = power decrease relative to baseline")
print("Red = power increase relative to baseline")
print(f"Number of epochs averaged: {n_epochs}")

TipHint

A Gaussian pulse centred at 300 ms can be created as amplitude * np.exp(-((times - 0.3)**2) / (2 * width**2)) where width controls the duration (try 0.05 for a 50 ms standard deviation). p300_template = p300_amplitude * np.exp(

Exercise 15: Compute ERP signal-to-noise ratio

Using the same P300 simulation setup as Exercise 14, compute the signal-to-noise ratio (SNR) of the ERP as the peak amplitude divided by the standard deviation of the pre-stimulus baseline. Repeat the computation with 10, 25, 50, and 100 trials. Plot SNR as a function of the number of trials and verify that SNR grows approximately as \(\sqrt{N}\).

TipHint

For each number of trials, average that many epochs, measure the peak amplitude in the P300 window (200–500 ms), and measure the standard deviation of the baseline period (-200 to 0 ms). SNR = peak / baseline_std. To check the \(\sqrt{N}\) relationship, overlay a scaled \(\sqrt{N}\) curve on the plot. The theoretical prediction is that if you double the number of trials, the SNR should increase by a factor of \(\sqrt{2} \approx 1.41\).

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)

sfreq = 256
epoch_duration = 1.0
n_samples = int(sfreq * epoch_duration)
times = np.linspace(-0.2, 0.8, n_samples, endpoint=False)

p300_latency = 0.300
p300_amplitude = 5.0
p300_width = 0.050
noise_amplitude = 15.0

# Generate a large pool of epochs
max_trials = 150
all_epochs = np.zeros((max_trials, n_samples))
for i in range(max_trials):
    jitter = rng.normal(0, 0.02)
    trial_p300 = p300_amplitude * np.exp(
        -((times - (p300_latency + jitter)) ** 2) / (2 * p300_width ** 2)
    )
    noise = rng.standard_normal(n_samples) * noise_amplitude

trial_counts = [10, 25, 50, 100]

baseline_mask = (times >= -0.2) & (times < 0)
p300_mask = (times >= 0.2) & (times <= 0.5)

print("-" * 44)

for n in trial_counts:
    erp = all_epochs[:n].mean(axis=0)
    peak_amp = erp[p300_mask].max()
    baseline_std = erp[baseline_mask].std()
    snr = peak_amp / baseline_std
    snr_values.append(snr)
    print(f"{n:>10d} {peak_amp:>10.2f} {baseline_std:>12.3f} {snr:>8.2f}")

trial_counts = np.array(trial_counts)

# Theoretical sqrt(N) curve, scaled to match the first data point
sqrt_curve = snr_values[0] * np.sqrt(trial_counts / trial_counts[0])

# Plot
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(trial_counts, snr_values, "o-", color="#2c3e50", linewidth=2,

ax.plot(trial_counts, sqrt_curve, "--", color="#e74c3c", linewidth=1.5,
        label=r"Theoretical $\sqrt{N}$ scaling")
ax.set_xlabel("Number of trials")
ax.set_ylabel("SNR")
ax.set_title("ERP signal-to-noise ratio vs number of trials")
ax.legend()
ax.set_xticks(trial_counts)
plt.tight_layout()
plt.show()

# Verify sqrt(N) relationship
print(f"\nSNR ratios (each step):")
for i in range(1, len(trial_counts)):
    ratio = snr_values[i] / snr_values[i - 1]
    expected = np.sqrt(trial_counts[i] / trial_counts[i - 1])
    print(f"  {trial_counts[i-1]:>3d} -> {trial_counts[i]:>3d} trials: "
          f"SNR ratio = {ratio:.2f}, expected sqrt ratio = {expected:.2f}")

This is why ERP experiments need many trials: to get a 2x improvement in SNR, you need 4x as many trials. The exact values will not be a perfect match because we are working with a finite random sample, but the trend should be clear.

Exercise 16: Compare eyes-open vs eyes-closed resting-state PSD

Simulate two conditions: eyes-closed (with a strong alpha peak at 10 Hz) and eyes-open (with a weak or absent alpha peak). Compute the PSD for each condition, plot them overlaid, and compute the difference in alpha band power. This is the most basic resting-state EEG paradigm and the alpha blocking effect is one of the oldest findings in EEG research (Berger, 1929).

TipHint

Both conditions should have the same 1/f background noise. The eyes-closed condition gets a strong alpha oscillation (amplitude around 2.0) while the eyes-open condition gets a weak one (amplitude around 0.3) or none at all. Compute the PSD for both with the same parameters, plot them on the same axes, and shade the alpha band. Compute the alpha power difference as the integral of the PSD in the 8–13 Hz range for each condition.

NoteSolution 
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

rng = np.random.default_rng(42)

sfreq = 256
duration = 60
n_samples = sfreq * duration
times = np.arange(n_samples) / sfreq

def make_eeg(alpha_amp, rng_local):
    """Generate simulated EEG with a given alpha amplitude."""
    white = rng_local.standard_normal(n_samples)
    freqs_fft = np.fft.rfftfreq(n_samples, d=1 / sfreq)
    freqs_fft[0] = 1
    pink_filter = 1 / np.sqrt(freqs_fft)

alpha_mask = (freqs_psd >= 8) & (freqs_psd < 13)
alpha_closed = np.trapz(psd_closed[alpha_mask], freqs_psd[alpha_mask])
alpha_open = np.trapz(psd_open[alpha_mask], freqs_psd[alpha_mask])
alpha_diff = alpha_closed - alpha_open

print(f"Alpha power (eyes closed): {alpha_closed:.4f}")
print(f"Alpha power (eyes open):   {alpha_open:.4f}")
print(f"Difference:                {alpha_diff:.4f}")
print(f"Ratio (closed / open):     {alpha_closed / alpha_open:.2f}x")

ax.semilogy(freqs_psd, psd_closed, linewidth=1.5, color="#e74c3c",

groups = [
    ("Rest",      2.0, 0.3),
    ("Task-easy", 1.2, 0.25),
    ("Task-hard", 0.5, 0.2),
]

def simulate_subject_alpha(alpha_amp, rng_local):
    """Simulate one subject and return alpha band power."""
    white = rng_local.standard_normal(n_samples)
    freqs_fft = np.fft.rfftfreq(n_samples, d=1 / sfreq)
    freqs_fft[0] = 1
    pink_filter = 1 / np.sqrt(freqs_fft)
    pink = np.fft.irfft(np.fft.rfft(white) * pink_filter, n=n_samples)
    pink = pink / pink.std()

    eeg = pink + alpha_amp * np.sin(2 * np.pi * 10 * times)

    freqs_psd, psd = signal.welch(eeg, fs=sfreq, nperseg=1024, noverlap=512)
    mask = (freqs_psd >= 8) & (freqs_psd < 13)
    return np.trapz(psd[mask], freqs_psd[mask])

# Simulate all subjects
group_data = {}
for name, mean_amp, sd_amp in groups:
    powers = []
    for _ in range(n_subjects):
        amp = max(0.1, rng.normal(mean_amp, sd_amp))
        powers.append(simulate_subject_alpha(amp, rng))
    group_data[name] = np.array(powers)

# Print descriptive statistics
print(f"{'Group':<12} {'Mean':>8} {'SD':>8} {'Min':>8} {'Max':>8}")
print("-" * 48)
for name, data in group_data.items():
    print(f"{name:<12} {data.mean():>8.3f} {data.std():>8.3f} "
          f"{data.min():>8.3f} {data.max():>8.3f}")

# One-way ANOVA
f_stat, p_anova = f_oneway(*group_data.values())
print(f"\nOne-way ANOVA: F = {f_stat:.3f}, p = {p_anova:.6f}")

# Pairwise t-tests with Bonferroni correction
print("\nPairwise t-tests (Bonferroni corrected for 3 comparisons):")
group_names = list(group_data.keys())
n_comparisons = 3
for i in range(len(group_names)):
    for j in range(i + 1, len(group_names)):
        g1, g2 = group_names[i], group_names[j]
        t_stat, p_val = ttest_ind(group_data[g1], group_data[g2])
        p_corrected = min(p_val * n_comparisons, 1.0)
        sig = "*" if p_corrected < 0.05 else "n.s."
        print(f"  {g1} vs {g2}: t = {t_stat:.3f}, "
              f"p = {p_val:.6f}, p_corrected = {p_corrected:.6f} {sig}")

# Box plot
fig, ax = plt.subplots(figsize=(8, 5))
